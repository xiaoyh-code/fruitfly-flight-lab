# Gaussian Splats @ LSY
A collection of Gaussian splats trained and used at the Learning Systems and Robotics Lab, TUM. We use these splats in [splax](https://github.com/learnsyslab/splax) and [Crazyflow](https://github.com/learnsyslab/crazyflow).
