Research agenda / proposed experiments

下一步，
每次只加一個難題。

先令工廠避障更可靠，再做多障礙同 Landing。每個任務先訂好成功條件、資料分組同對照，之後先開始新一輪訓練。

以下任務尚未以本輪 3DGS + Flyvis 管線完成驗收。次數、誤差及成功率係建議驗收目標，唔係已達成表現；正式開跑前要固定設定。過往合成 MuJoCo 任務嘅結果唔等同工廠視覺驗收。目前本站公開本輪嘅工廠單障礙證據。
01
優先 · 待新一輪訓練

單障礙，換條路都得。

先核對更多工廠局部區域嘅碰撞幾何，擴大起點、終點與障礙相對位置分布。加入固定路線控制器同視覺遮蔽對照，檢查模型會唔會只係記住一條路。

建議預先訂明的驗收
  • 保留至少 50 個未見過嘅測試配置；由至少 3 個獨立訓練 seeds 重跑。
  • 每次都報到達、碰撞、最小淨距、路徑長度與時間；建議目標為到達率 ≥ 90%、代理碰撞 0 次。
  • 訓練、驗證、測試按配置分組；視覺對照與基線使用相同測試配置。
02
待任務 01 完成

多障礙，同時揀路。

循序增加 2–5 個可見、已核對碰撞範圍嘅障礙，改變通道寬度與排列。先用靜態障礙；移動物件之後獨立成一個實驗。

建議預先訂明的驗收
  • 按障礙數量分層，至少 10 組未見排列／每一難度；避免相近排列流入訓練與測試兩邊。
  • 建議每一難度到達率 ≥ 90%、碰撞 0 次；同時報最差難度，唔只報平均值。
  • 保存完整 RGB、逐步 observation／action、碰撞物件 ID，以及失敗影片。
03
需新增視覺與高度控制

Landing，真正落到台。

新增可見降落平台、向下相機或可觀察平台嘅視角，以及垂直速度控制。先做無障礙接近與降落，再加位置偏移、平台大小與外觀變化。

建議預先訂明的驗收
  • 「落地」需確認平台接觸後穩定保持 1 秒；懸停或接近地面唔算成功。
  • 起始建議：水平誤差 ≤ 0.10 m、接觸前下降速度 ≤ 0.20 m/s、傾角 ≤ 10°；先核對物理與平台尺寸再鎖定。
  • 至少 50 次保留測試；報成功率、硬着陸、平台外落地及各誤差分布。原有合成 Landing 結果唔當作工廠視覺降落結果。
04
待多障礙與 Landing 分別通過

避完障，再安全降落。

連接導航、接近、下降與着陸四個階段。測試順序控制，保留整段任務證據；任何一個階段失敗都計入整體任務失敗。

建議預先訂明的驗收
  • 至少 50 個新「路線 + 平台」組合，重新保留測試組，唔重用先前調參配置。
  • 同時報整體成功率與各階段失敗率；建議整體 ≥ 80%、導航碰撞 0 次、無硬着陸。
  • 成功片同失敗片都保存，標記階段轉換時間，檢查失敗係規劃、控制定觀察造成。
05
感測與泛化研究

唔再依賴完美狀態。

逐項加入速度估計誤差、相機延遲、亮度及遮擋變化，再測移除或擾動理想目標訊號。另設距離標註實驗，先量度視覺特徵是否包含深度資訊。

建議預先訂明的驗收
  • 每次只改一種誤差，再研究組合；為各強度至少保留 30 個配對測試 seeds。
  • 報成功率隨誤差嘅變化，對照原始理想狀態模型；延遲須量度完整控制迴路。
  • 深度另報未見場景嘅誤差及基線，不能單靠避障成功率宣稱已識測距。
06
較後階段 · 場景未校準

由工廠，行去另一個空間。

校園先留喺場景資料庫。開始訓練前，要確認尺度、重力方向、可飛區域與障礙網格，再從短距離局部任務開始。戶外返航與 4DGS 動態場景另立研究。

開始訓練前的必要工作
  • 用可量度參考物校準尺度，抽查視覺表面與碰撞表面位置；記錄誤差。
  • 分開報直接遷移、少量微調與重新訓練三種設定，測試區域不能參與訓練。
  • 真機、戶外長距離及動態場景未有驗收日期或結果；須建立各自嘅感測、物理與評估流程。

下一輪開始前，
先補好紀錄。

新實驗應逐筆保存 run ID、episode ID、seed、時間、相機幀、observation、教師與策略 action、訓練／驗證標記，以及每個 epoch 嘅 loss。今次缺少嘅欄位，保留為缺少，唔事後估出嚟。

用驗證組比較改動；鎖定方法後，再用未參與調參嘅保留測試組驗收。所有最終基線用相同配置比較，並以不同訓練 seeds 報變異。失敗輪次與成功輪次一齊交代，學生先能判斷改動是否有效。
